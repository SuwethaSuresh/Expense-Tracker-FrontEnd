# Expense Tracker

A simple and responsive web-based Expense Tracker built using HTML, CSS, and JavaScript to record, manage, filter, and track daily expenses.

## Features

- Add daily expenses
- Select expense categories
- View total expenses
- Track number of transactions
- View today's expenses
- Filter expenses by category
- View recent expenses
- Delete expenses
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

Expense-Tracker-FrontEnd/

│

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding and managing your expenses.
